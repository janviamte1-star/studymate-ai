# StudyMate AI 📚

An AI-powered study assistant that helps students learn smarter.

## Features

- Upload PDF, DOCX, and TXT notes
- AI Chat with Notes
- AI Quiz Generator
- Flashcards
- Progress Dashboard
- Quiz History
- User Authentication

## Tech Stack

Frontend:
- React
- Tailwind CSS

Backend:
- FastAPI
- Python

AI:
- Google Gemini

Database:
- SQLite
- ChromaDB

Deployment:
- Vercel
- Render
